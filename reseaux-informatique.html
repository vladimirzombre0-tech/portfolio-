04. Adressage IP et sous-réseaux

Une adresse IPv4 est composée de 32 bits. Le masque de sous-réseau indique quelle partie identifie le réseau et quelle partie identifie la machine.

Réseau : 192.168.1.0/24
Masque : 255.255.255.0
Hôtes utiles : 254 (de .1 à .254)
Broadcast : 192.168.1.255

Découpage en /26 (masque 255.255.255.192) :
192.168.1.0/26   192.168.1.64/26
192.168.1.128/26   192.168.1.192/26
=> 4 sous-réseaux de 62 hôtes chacun

05. Commandes de diagnostic

$ ipconfig /all    # Windows : configuration IP
$ ip a             # Linux : interfaces réseau
$ ping 8.8.8.8     # tester la connectivité
$ tracert google.com  # Windows : chemin des paquets
$ traceroute google.com # Linux : chemin des paquets
$ nslookup google.com  # résolution DNS
